# 巡线与视觉引导打靶机器人

[English](README.md)

本项目使用 STM32F103C8T6 完成巡线与编码器停车，使用 CanMV K230 完成视觉找靶、二轴云台控制和激光打靶。它是 2026 年上海电机学院机器人校内赛的参赛原型。原始[比赛总结](docs/比赛总结.txt)记录成绩为 **85/100 分、第四名**，没有逐项评分单。

> **当前状态：**比赛时 STM32 与 K230 的到站通信没有调通。K230 根据视觉对准状态自主触发激光，无法确认小车是否到站；失去对准后还可能重新触发三发。仓库展示了当时的技术方案及赛后整理结果，不能据此认定已经满足所有竞赛规则。

## 已有模块

| 模块 | 实现 | 仍需验证 |
| --- | --- | --- |
| 巡线 | 八路传感器、加权线位、转向 PID | 实际循线偏差与丢线恢复 |
| 行走与停车 | TB6612、20 kHz PWM、TIM2/TIM4 编码器、固定脉冲阈值 | 双轮速度闭环与各站停车误差 |
| 视觉云台 | 矩形检测、霍夫圆备用、两轴串口舵机 | 圆靶误识别率与真实激光落点 |
| 激光时序 | 对准 15 帧后标称连续打三次，每次亮 500 ms | 失准重触发、实际脉宽与每站限发 |
| 双板通信 | STM32 输出 PB15 电平，K230 配置 UART 接收引脚 | 两板尚无一致且可用的握手协议 |

文件结构：`stm32/` 为 STM32 固件与 Makefile；`k230/k230_fixed.py` 为比赛最终版 K230 程序；`k230/legacy_200ms.py` 是早期 200 ms 版本，仅供回溯；`docs/` 保存比赛总结和[赛后整理说明](docs/release-notes.md)。详细接线见 [英文 README](README.md#hardware-and-signal-flow)。

## 构建与部署

需要 ARM GNU 工具链、GNU Make、STM32Cube FW F1 v1.8.7 和 STM32CubeProgrammer。赛后整理版已在 Windows 上使用 STM32CubeIDE 2.1.1 自带的 GCC 14.3.1 与 STM32Cube FW F1 v1.8.7 **完成编译和链接**；尚未重新上板测试。

```sh
make -C stm32 \
  FW_REPO=/path/to/STM32Cube_FW_F1_V1.8.7 \
  TOOLCHAIN_PREFIX=arm-none-eabi- \
  all
```

工具链不在 `PATH` 时，将 `TOOLCHAIN_PREFIX` 设为完整路径，末尾保留 `arm-none-eabi-`。构建产物位于 `stm32/build/`。STM32 可用 SWD 和 STM32CubeProgrammer 烧录；K230 使用提供 `cv_lite` 等模块的 CanMV 环境运行 `k230_fixed.py`。

原车的停车脉冲阈值、PID 参数、像素参考点 `(120, 150)` 和舵机步长均为现场调参结果。移植到其他底盘、镜头或场地前，需要重新测量和标定。

## 测试提醒与已知不足

- 初次测试请断开激光，先用 LED 代替；当前 STM32 程序初始化后即开始驱动车轮，K230 程序也可能凭视觉对准自动点亮激光。
- K230 主循环因 Python 异常退出时会将激光引脚拉低，但没有独立的硬件限时保护；设备卡死等情况仍需物理保护措施。
- 双板到站与发射完成握手、按站计数限发尚未实现。STM32 固定停车 8 秒，不能保证视觉端已完成工作。
- 丢线恢复没有超时停机；请先固定车体进行台架测试。
- 编译成功不代表已验证真实停车误差、命中环数或整机供电合规。
